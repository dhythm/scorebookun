# 実機 1 試合通し検証

このチェックシートは、ブラウザーのモバイル表示では検出できない PWA、屋外視認性、
タッチ操作、オフライン復帰、印刷の問題を実機で確認するために使う。
未記入のシートを「検証済み」として扱わない。

- 実施日:
- 検証者:

- 端末:
- OS:
- ブラウザーとバージョン:
- インストール方法: ブラウザー / ホーム画面 PWA
- 試合形式: 7 回 / 9 回 / その他:
- 総合判定: 未実施 / 合格 / 条件付き合格 / 不合格

## 対象端末

最低限、次の 2 経路で別々に 1 試合を記録する。

- [ ] iPhone の最新安定版 iOS + Safari またはホーム画面 PWA
- [ ] Android のサポート対象 OS + Chrome またはホーム画面 PWA

## 試合前

- [ ] 新規試合を作成し、先攻・後攻、打順、控え、先発投手を登録できる
- [ ] 縦画面と横画面で主要ボタンや現在状況が欠けない
- [ ] 屋外モードで直射日光下でも得点、アウト、走者、現在打者を判読できる
- [ ] 機内モードで再起動しても記録画面を開ける

## 1 試合の入力

- [ ] 単打、二塁打、三塁打、本塁打を記録する
- [ ] 内野安打と失策を記録し、既定進塁を確認する
- [ ] ゴロで走者封殺を選び、野選として表示・集計される
- [ ] 併殺を記録し、守備連係（例: 6-4-3）とプレー順が表示される
- [ ] 外野フライで「浅い」「深い」を両方記録し、深い時だけ既定タッチアップされる
- [ ] 犠打、犠飛、四球、死球、三振、振り逃げを記録する
- [ ] 盗塁、ダブルスチール、盗塁死、牽制死、暴投、捕逸、ボークを記録する
- [ ] ダイヤ上の走者から走塁入力を開始できる
- [ ] 代打、代走、守備交代、投手交代を記録する
- [ ] 「進塁・打点だけ修正」を保存できる
- [ ] 後続記録が無効になる編集で確認が出て、キャンセルと確定が正しく働く
- [ ] 複数段 Undo / Redo、イニング開始へ戻す、削除済みの記録から復元を確認する
- [ ] 試合メモを追加する
- [ ] 各イニング終了時の残塁が実際の走者数と一致する

## 信頼性

- [ ] 記録途中でオフラインにし、入力後にオンライン復帰しても記録が残る
- [ ] 同じ試合を別タブで更新すると競合バナーが出て、古い側では入力できない
- [ ] 競合側で最新版を読み込み、得点・走者・打順が更新される
- [ ] 保存失敗を再現できる環境では「保存されていません」が常設表示される
- [ ] 新版デプロイ後に更新案内が出て、再読み込み後も試合データが残る
- [ ] 画面をバックグラウンドへ移動し、復帰後も入力を継続できる
- [ ] 端末の回転、画面ロック、低電力状態で記録が失われない

## 試合後

- [ ] 最終得点、安打、失策、盗塁、チーム残塁が手計算と一致する
- [ ] 失策内訳が守備位置別に一致する
- [ ] 各回表裏の残塁表示がスコアブックと一致する
- [ ] 打撃成績と投手成績が手計算と一致する
- [ ] テキスト共有と JSON 書き出しを実行できる
- [ ] 「印刷/PDF」で横向きの両チーム打順×イニング表が欠けずに出力される
- [ ] PDF をチーム共有アプリへ添付し、文字が判読できる
- [ ] 試合履歴から同じ試合を開き直せる
- [ ] 履歴容量超過時、明示的に退避 JSON を保存してから古い履歴を削除できる
- [ ] 退避 JSON を取り込み、対象試合を履歴から開き直せる
